# Portfolio personal de Franco Alegre

Sitio web personal para presentar el perfil profesional de Franco Alegre, sus proyectos de desarrollo, formación, certificaciones y trayectoria en informática y soporte IT.

## Contenido

- Presentación profesional y enlaces de contacto.
- Sección de Yui con capacidades, enfoque de privacidad, estado actual y roadmap.
- Seis proyectos públicos con enlaces a demos y repositorios disponibles.
- Certificaciones con carrusel interactivo, controles por teclado y gesto de arrastre.
- Habilidades, certificaciones y trayectoria.
- Formulario para preparar un email de contacto.

## Tecnologias

HTML, CSS, JavaScript, Tailwind CSS, Lucide Icons e iconos SVG de marca.

## Desarrollo local

Requisitos: Node.js y npm.

```sh
npm install
npm run build:css
```

Después, abrí `index.html` en un navegador o utiliza una extensión de servidor local de VS Code. El archivo `tailwind.css` compilado se publica junto con el sitio para que GitHub Pages no dependa del CDN de Tailwind.
