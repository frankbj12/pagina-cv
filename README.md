# Portfolio personal de Franco Alegre

Sitio web personal para presentar el perfil profesional de Franco Alegre, sus proyectos de desarrollo, formacion, certificaciones y experiencia en informatica y soporte IT.

## Contenido

- Presentacion profesional y enlaces de contacto.
- Proyecto personal Yui, un asistente local en desarrollo.
- Proyectos web seleccionados.
- Habilidades, certificaciones y trayectoria.
- Formulario para preparar un email de contacto.

## Tecnologias

HTML, CSS, JavaScript, Tailwind CSS via CDN y Lucide Icons.

## Desarrollo local

Abri `index.html` en un navegador o utiliza una extension de servidor local de VS Code.
