Proyecto destacado

Yui.

Asistente personal por voz para Windows, desarrollado en Python y diseñado para funcionar en local. El proyecto prioriza la privacidad y crece de forma incremental hacia una experiencia de asistencia cada vez más completa.

En desarrollo activo · Proyecto personal

Qué estoy construyendo

Un asistente que combina conversación natural, voz y herramientas de Windows para ayudar con tareas cotidianas y de desarrollo. El modelo Qwen 2.5 3B se ejecuta localmente con Ollama, sin APIs externas de IA.

Python 3.11 Ollama · Qwen 2.5 3B Vosk Edge-TTS · pyttsx3 SQLite Windows

Privacidad por diseño

La IA, el reconocimiento de voz y la memoria funcionan localmente. La síntesis principal usa Edge-TTS; pyttsx3 ofrece una alternativa local.

Capacidades de la base actual

Conversación con contexto

Historial reciente, resúmenes progresivos y memoria de preferencias elegidas por el usuario.

Interacción por voz

Reconocimiento local en español con Vosk y respuesta hablada con Edge-TTS o pyttsx3.

Memoria y contexto

Preferencias persistentes, resúmenes de conversaciones y contexto del entorno con SQLite.

Recordatorios y rutinas

Recordatorios en lenguaje natural, avisos por prioridad y rutinas para tareas frecuentes.

Herramientas para Windows

Encuentra proyectos y aplicaciones, consulta el sistema y trabaja con archivos y multimedia.

Acciones seguras: las operaciones destructivas requieren confirmación explícita; el modelo no controla directamente el sistema.

Estado del proyecto

Base funcional; evolución en marcha

Ya cuenta con sesión conversacional, enrutamiento por Skills, memoria y recordatorios en SQLite, rutinas, contexto del sistema y confirmaciones para acciones sensibles. La suite documentada en el README ronda los 328 tests.

En desarrollo activo

Roadmap · próximas etapas

  • Inicio automático y presencia continua en Windows.
  • Referencias contextuales más ricas y automatización segura de tareas encadenadas.
  • Una interfaz gráfica para complementar la experiencia por voz.
